# Delivery tasks

Each task must identify the requirement it advances, affected module/source set, expected test, and dependencies.

## Foundation

- [ ] Add or update pure models, contracts, and compatibility behavior with focused tests.

## Data and orchestration

- [ ] Implement mappings, repositories, service behavior, and degraded paths with failure-path tests.

## Shared presentation

- [ ] Implement state, intents, effects, and accessible localized UI states.

## Platform integrations

- [ ] Add only the thin Android and iOS adapters required by the accepted design.

## Verification

- [ ] Run the discovered automated matrix.
- [ ] Capture required emulator, simulator, physical-device, multi-device, backend, and distribution evidence.
- [ ] Reconcile every acceptance criterion and record residual gates.

Remove irrelevant sections rather than creating empty work.
